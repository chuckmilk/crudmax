# Crudmax Vol. 1

A plug-in suite for Mac by The Holographic. Audio Unit for Logic Pro, VST3 for Ableton Live (Apple Silicon and Intel, macOS 12 or later).

- **Halation** - a synth that grows sounds out of pictures
- **Xenorack** and **Xenorack FX** - an alien modular rack, as an instrument and as an effect
- **Vapor Raid** - a house drum, bass and chord stab machine with an arcade game on its screen

## Download

**[Crudmax-Vol-1.pkg](https://github.com/chuckmilk/crudmax/releases/latest/download/Crudmax-Vol-1.pkg)**

Open it and follow the installer. It installs for your user account only, so it never asks for a password.
The first time, macOS may say the installer is from an unidentified developer: right-click the file and choose
Open, or go to System Settings > Privacy & Security and press "Open Anyway".

## Updates

The installer also sets up a small updater. A few times a day it checks this page's release list
(`manifest.txt`, signed) and installs any newer plug-in version on its own. To check right away, open
"Check for Crudmax Updates" in the Applications folder inside your home folder.
